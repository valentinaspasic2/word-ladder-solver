# Word Ladder Solver
A C program that builds and solves word ladders between two words using linked lists and shortest path search.

## How it works

The program builds a word ladder by changing one letter at a time, with each new word required to exist in the provided dictionary.

It uses linked lists to store word ladders and a breadth first search approach to explore valid one letter changes and find the shortest ladder between the starting and final words.

The project also uses dynamic memory allocation, binary search, file input, and string manipulation.
